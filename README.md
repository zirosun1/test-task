## Запуск и проверка

Запускай команды из корня репозитория:

```sh
php 03-b2b-prices/tests.php
php 03-b2b-prices/run.php K-002 B-106 12
php 06-open-improvement/06-monitor-prototype.php
```

Тесты задания 03 используют временный кеш и не меняют `03-b2b-prices/var/cache.json`. Команда `run.php` меняет этот файл, поэтому перед повторными опытами сохрани его копию.

Все 9 проверок задания 03 завершились успешно. Прототип задания 06 на данных инцидента показывает 8 ожидающих заказов; старейший — `#88414`, он ждёт 187 минут.
